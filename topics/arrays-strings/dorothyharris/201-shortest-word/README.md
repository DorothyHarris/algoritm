v# Самое короткое слово

easy · в процессе

## Условие

Напишите функцию, которая принимает предложение, состоящее из слов, разделённых пробелами, и возвращает длину самого короткого слова.

```js
const str = "lorem ipsum dolor sit amet";

console.log(shortestWord(str)); // 3
```

## Примеры

| Вход | Выход | Пояснение |
|---|---|---|
| `"lorem ipsum dolor sit amet"` | `3` | Самое короткое слово `sit` |
| `"bitcoin take over the world maybe who knows perhaps"` | `3` | Самых коротких слов два, `the` и `who`, ответ один: `3` |
| `"algorithm"` | `9` | Одно слово, оно же самое короткое |

## Заметки

Идея: разбить строку по пробелам через `split(" ")`, получить длины слов через `map` и взять минимум через `Math.min(...length)`.

Сложность: время O(n), память O(n), где n — длина строки.

**Осторожно, может переполниться стек, и всё упадёт.** `Math.min(...length)` передаёт каждое число отдельным аргументом функции, а аргументы кладутся на стек. Если слов очень много, стек переполняется, и функция падает с `RangeError: Maximum call stack size exceeded`. Я проверила в Node 22: на 100 000 слов ещё работает, на 200 000 уже падает. Надёжнее искать минимум циклом или через `reduce`: там нет огромного числа аргументов.
