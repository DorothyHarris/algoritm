# Two Sum

[LeetCode #1](https://leetcode.com/problems/two-sum/) · easy · в процессе

## Условие

Дан массив целых чисел `nums` и целое число `target`. Нужно вернуть индексы двух чисел, сумма которых равна `target`.

- Гарантируется, что ответ ровно один.
- Один и тот же элемент нельзя использовать дважды.
- Индексы можно вернуть в любом порядке.

Ограничения: `2 <= nums.length <= 10^4`, `-10^9 <= nums[i] <= 10^9`, `-10^9 <= target <= 10^9`.

## Примеры

| Вход | Выход | Пояснение |
|---|---|---|
| `nums = [2, 7, 11, 15]`, `target = 9` | `[0, 1]` | `nums[0] + nums[1] = 2 + 7 = 9` |
| `nums = [3, 2, 4]`, `target = 6` | `[1, 2]` | `2 + 4 = 6`, а `3 + 3` использовать нельзя, это один элемент |
| `nums = [3, 3]`, `target = 6` | `[0, 1]` | Значения могут повторяться, индексы разные |
