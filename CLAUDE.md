# Инструкции для Claude

Учебный репозиторий с алгоритмическими задачами, работают несколько человек. Правила и структура описаны в `README.md`, следуй им.

- Путь: `topics/<тема>/<ник>/<номер>-<задача>/<язык>/solution.<ext>`, рядом `README.md` и `CHANGELOG.md` задачи. Образец: `topics/arrays-strings/dorothyharris/1-two-sum/`.
- `<ник>` — GitHub username в нижнем регистре. Если неизвестен, спроси, не выдумывай. Работай только в папке текущего пользователя.
- `<номер>` — следующий свободный номер задач пользователя в этой теме, посчитай существующие папки.
- Имена папок и файлов на английском, `kebab-case`. Тексты (README, ченджлог, комментарии) на русском.
- Тесты для JS/TS пишем на Jest, запуск `npx jest <путь к задаче>` из корня.
- После изменения решения добавляй запись сверху в `CHANGELOG.md` (дата, что сделано, комментарии).
- Не решай задачу за пользователя, если он об этом не просил: по умолчанию оставляй заготовку и тесты.
